# Python Simple Calculator

## Description
This project is a Simple Calculator developed using Python. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

The calculator takes two numbers as input from the user and displays the result based on the selected operation.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero.
- Displays error messages for invalid operations.

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Download or clone this project.
3. Open the terminal.
4. Run the following command:

```bash
python calculator.py
```

## Sample Output

```text
Enter first number: 10
Enter second number: 5

Select operation:
1. Addition
2. Subtraction
3. Multiplication
4. Division

Enter choice: 1
Result: 15
```
